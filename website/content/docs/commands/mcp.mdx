## Usage

```bash
rft mcp
```

Starts an MCP (Model Context Protocol) server using stdio transport. This command is intended to be called by AI agents, not run manually.

The server exposes all rft commands as MCP tools. See [MCP Integration](/docs/integrations/mcp) for setup and available tools.

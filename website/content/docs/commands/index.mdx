## Command Reference

| Command | Description |
|---------|-------------|
| [`rft init`](/docs/commands/init) | Analyze compose file, suggest port fixes, generate config |
| [`rft list`](/docs/commands/list) | Show all worktrees with ports and container status |
| [`rft start`](/docs/commands/start) | Start Docker Compose stacks in parallel. `--dry-run` to preview |
| [`rft stop`](/docs/commands/stop) | Stop running stacks |
| [`rft restart`](/docs/commands/restart) | Restart stacks (stop + start) |
| [`rft watch`](/docs/commands/watch) | Start stacks and auto-restart on file changes |
| [`rft logs`](/docs/commands/logs) | Stream container logs. `--no-follow` for snapshot |
| [`rft promote`](/docs/commands/promote) | Transfer changes to current branch. `--dry-run` to preview |
| [`rft clean`](/docs/commands/clean) | Full cleanup: stop, remove worktrees, prune Docker |
| [`rft status`](/docs/commands/status) | One-line status for shell prompt integration |
| [`rft completions`](/docs/commands/completions) | Generate shell completions (bash/zsh/fish) |
| [`rft mcp`](/docs/commands/mcp) | Start MCP server for AI agent integration |

## Index-Based Selection

Most commands accept optional worktree indices. Indices are shown in the `rft list` output.

```bash
# Operate on all worktrees
rft start

# Operate on specific worktrees
rft start 1 3

# Single worktree
rft logs 1
```

When no indices are provided, the command operates on all worktrees.
